## 咖啡业务模块详解

**根路径**: `src/main/java/com/ruoyi/project/coffee/`

### 标准模块结构

每个业务模块的标准分层：
```
模块名/
├── controller/               后台管理 Controller（Web 表单/Ajax）
│   └── XxxController.java     处理后台页面请求
│
├── domain/                   领域对象
│   ├── Xxx.java               数据库实体（对应表结构）
│   ├── XxxVO.java             视图对象（返回给前端）
│   └── XxxDTO.java            数据传输对象（接收前端参数）
│
├── mapper/                   MyBatis 数据访问接口
│   └── XxxMapper.java         定义数据库操作方法
│
└── service/                  业务逻辑层
    ├── IXxxService.java       服务接口定义
    └── impl/
        └── XxxServiceImpl.java 服务实现类（@Service、@Transactional）
```

### 接口层 (api/)

小程序 REST API，返回 JSON 格式数据。

| 文件 | 职责 | 关键方法 |
|------|------|---------|
| ProductApiController | 商城商品接口 | `getProductList()` - 列表+画像推荐<br>`getProductDetail()` - 详情+浏览采集 |
| CartApiController | 商城购物车 | `addCart()` - 加购+证据采集<br>`updateCart()` - 修改数量<br>`deleteCart()` - 移除 |
| OrderApiController | 商城订单 | `createOrder()` - 创建订单+金额重算<br>`payOrder()` - 余额支付 |
| ScanMenuApiController | 点单商品接口 | `getProducts()` - 列表+画像推荐<br>`getProductDetail()` - 详情+规格 |
| ScanCartApiController | 点单购物车 | `addCart()` - 加购+规格+证据采集 |
| ScanOrderApiController | 点单订单 | `createOrder()` - 创建+金额重算+分配取餐号<br>`urgeOrder()` - 催单 |
| WalletApiController | 钱包余额 | `getBalance()` - 查询余额<br>`getLogs()` - 流水明细 |
| MemberApiController | 会员信息 | `getMemberInfo()` - 会员等级、折扣 |
| ActivityApiController | 营销活动 | `getActiveList()` - 查询进行中活动 |
| OfflineActivityApiController | 线下活动 | `getList()` - 活动列表<br>`signup()` - 报名 |
| AddressApiController | 收货地址 | 地址 CRUD |
| OrderRefundApiController | 商城退款 | `applyRefund()` - 申请退款 |
| ScanOrderRefundApiController | 点单退款 | `applyRefund()` - 申请退款 |


### 重要 Mapper XML 说明

| 文件 | 关键 SQL | 技术要点 |
|------|---------|---------|
| TProductMapper.xml | decreaseStock | 乐观锁防超卖：`WHERE stock >= #{quantity}` |
| TWalletMapper.xml | deductBalance | 乐观锁防透支：`WHERE balance >= #{amount}` |
| ScanOrderMapper.xml | updateScanOrderStatus | CAS 状态机：`WHERE status = #{oldStatus}` |
| UserProfileMapper.xml | selectChangedUserIds | 增量查询：10分钟重叠窗口避免边界漏算 |
| UserProfileMapper.xml | selectBehaviorEvidence | 全部有效证据：JOIN 商品表获取属性 |
| UserProfileMapper.xml | selectPurchaseEvidence | 有效订单：UNION 商城和点单订单 |
